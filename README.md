# Inversiones Ave Fénix

Sitio web de **Inversiones Ave Fénix**, agencia costarricense de reclutamiento y
dotación de personal.

🌐 **En vivo:** [inversionesavefenix.com](https://inversionesavefenix.com)

## Sobre el sitio

Landing corporativa con la información de la agencia, sus servicios y un formulario
de **"Trabajá con nosotros"** para que los candidatos apliquen en línea.

## Tecnología

- HTML, CSS y JavaScript.
- Formulario de aplicación conectado a Google Sheets vía Google Apps Script.
- Desplegado en Vercel.
